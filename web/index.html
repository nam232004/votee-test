Votee Wordle Solver

This page calls the same solver as the CLI. Every guess goes to the live API at wordle.votee.dev.

The API has no session: without a seed every request is a different secret, so we pin one seed for the whole run.

We choose the answer, so this is a controlled test. It does not have to be a real word — kshjc or zzzzz still solve. Letters a–z only; the API will not accept anything else as a guess.
