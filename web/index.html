Votee Wordle Solver

Giao diện gọi vào cùng một solver với CLI. Mọi lượt đoán đều đi tới API thật tại wordle.votee.dev.

API không lưu trạng thái: thiếu seed thì mỗi request là một từ khác nhau, nên phải ghim một seed cho cả phiên.

Ta tự đặt đáp án, nên đây là môi trường kiểm tra có kiểm soát. Không cần là từ có nghĩa — kshjc hay zzzzz đều giải được. Chỉ nhận chữ a–z, vì API chỉ nhận guess gồm chữ cái.
